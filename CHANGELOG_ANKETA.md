# Обновление анкеты

- Удален счетчик обязательных пунктов и универсальный вопрос о частоте выполнения цели.
- Обновлены шесть целей питания, первые пять целей движения и шесть целей восстановления.
- Уточняющие ответы сохраняются в JSON в `details`; ежедневные действия в `daily_actions`.
- Действие текущего сезона отображается в трекере.
- Добавлены итоговые карточки перед отправкой анкеты.
- Учетные записи и данные прогресса не удалялись.

## Ограничения

- Пять остальных целей движения оставлены с прежними названиями, без новых уточняющих вопросов, поскольку новые вопросы не предоставлены.
- Старые заполненные анкеты не преобразуются автоматически в новую схему; администратор может сбросить старые ответы через панель после создания резервной копии.
- Выполнена проверка синтаксиса PHP и JavaScript; полноценное браузерное тестирование не выполнялось.
