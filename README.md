# Будь в форме BGP – интерактивный прототип

## Запуск

Требуется PHP 8.1+.

```bash
cd bgp-app
php -S localhost:8080 -t public router.php
```

Открыть http://localhost:8080.

Демо-аккаунты:
- Администратор: `admin` / `Admin2026!`
- Участник: `demo` / `Demo2026!`

**Перед публичной публикацией обязательно смените демо-пароли, удалите тестовые учетные записи и настройте HTTPS.**

## Структура
- `public/` – PHP API, интерфейс, PWA и стили.
- `data/store.json` – пользователи, команды, отметки, показатели, эксперты, уведомления и розыгрыш.
- `router.php` – маршрутизация для встроенного PHP-сервера.

## Публикация
Для тестового развертывания подойдет любой PHP-хостинг с постоянной записью файлов, HTTPS и возможностью назначить document root на `public/`. Например, бесплатный PHP-хостинг InfinityFree (условия и доступность нужно проверить при регистрации). Предлагаемый адрес: `bgp-forma-demo.infinityfreeapp.com` **не зарегистрирован и не проверен на доступность**. Загрузите содержимое проекта, назначьте `public/` корнем сайта, оставьте `data/` за пределами публичного каталога. Для хостинга, где нельзя изменить корень сайта, требуется отдельная безопасная конфигурация.

## Реализовано
- Адаптивная мобильная и десктопная верстка, PWA manifest и service worker.
- Сессии PHP, хеширование паролей, роли участника и администратора.
- Создание участников и автоматическое распределение по 10 человек с группировкой по цели.
- Отметки привычек, прогресс за 21 день, правило нулевого вклада в команду при личном прогрессе ниже 50%.
- Учет шагов и веса, автоматические ачивки за 1, 7, 10, 14 и 21 день.
- Командный рейтинг, просмотр достижений других участников, доска экспертов.
- Шансы от 1 до 7 и финализация администратором, публикация уведомлений.

## Ограничения прототипа
- Bitrix24 не подключен: интеграция потребует доступа к порталу и согласования API.
- Рейтинг по шагам и динамике веса, полноценное анкетирование, сценарии сезонности, чат между участниками и механизм розыгрыша пока не реализованы.
- Учет шансов задается администратором; автоматические правила начисления не определены.
- Данные демонстрационные. Для эксплуатации необходимы резервные копии, аудит прав, защита от CSRF, лимитирование попыток входа и атомарные транзакции для конкурентных записей в JSON.
- PWA кеширует интерфейс, но отправка данных требует подключения к серверу.


## Раздел «Эксперты BGP» (обновление)
Вкладка «Эксперт»: 9 демонстрационных профилей, 3 категории, фильтр по категориям, поиск по имени и теме, подробный профиль, адаптивная верстка. Имена и описания – демонстрационные данные из макета. Фотографии не включены, вместо них инициалы. Контакты не заполнены: после внесения реальных адресов в `data/store.json` появится ссылка для письма. Внутренний чат и самостоятельное редактирование профилей пока не реализованы.
