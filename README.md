# Будь в форме BGP – интерактивный прототип

## Запуск

Требуется PHP 8.1+.

```bash
cd bgp-app
php -S localhost:8080 -t public router.php
```

Открыть http://localhost:8080.

Демо-аккаунты:
- Администратор: `admin` / `Admin2026!`
- Участник: `demo` / `Demo2026!`

**Перед публичной публикацией обязательно смените демо-пароли, удалите тестовые учетные записи и настройте HTTPS.**

## Структура
- `public/` – PHP API, интерфейс, PWA и стили.
- `data/store.json` – пользователи, команды, отметки, показатели, эксперты, уведомления и розыгрыш.
- `router.php` – маршрутизация для встроенного PHP-сервера.

## Публикация
Для тестового развертывания подойдет любой PHP-хостинг с постоянной записью файлов, HTTPS и возможностью назначить document root на `public/`. Например, бесплатный PHP-хостинг InfinityFree (условия и доступность нужно проверить при регистрации). Предлагаемый адрес: `bgp-forma-demo.infinityfreeapp.com` **не зарегистрирован и не проверен на доступность**. Загрузите содержимое проекта, назначьте `public/` корнем сайта, оставьте `data/` за пределами публичного каталога. Для хостинга, где нельзя изменить корень сайта, требуется отдельная безопасная конфигурация.

## Реализовано
- Адаптивная мобильная и десктопная верстка, PWA manifest и service worker.
- Сессии PHP, хеширование паролей, роли участника и администратора.
- Создание участников и автоматическое распределение по 10 человек с группировкой по цели.
- Отметки привычек, прогресс за 21 день, правило нулевого вклада в команду при личном прогрессе ниже 50%.
- Учет шагов и веса, автоматические ачивки за 1, 7, 10, 14 и 21 день.
- Командный рейтинг, просмотр достижений других участников, доска экспертов.
- Шансы от 1 до 7 и финализация администратором, публикация уведомлений.

## Ограничения прототипа
- Bitrix24 не подключен: интеграция потребует доступа к порталу и согласования API.
- Рейтинг по шагам и динамике веса, полноценное анкетирование, сценарии сезонности, чат между участниками и механизм розыгрыша пока не реализованы.
- Учет шансов задается администратором; автоматические правила начисления не определены.
- Данные демонстрационные. Для эксплуатации необходимы резервные копии, аудит прав, защита от CSRF, лимитирование попыток входа и атомарные транзакции для конкурентных записей в JSON.
- PWA кеширует интерфейс, но отправка данных требует подключения к серверу.


## Раздел «Эксперты BGP» (обновление)
Вкладка «Эксперт»: 9 демонстрационных профилей, 3 категории, фильтр по категориям, поиск по имени и теме, подробный профиль, адаптивная верстка. Имена и описания – демонстрационные данные из макета. Фотографии не включены, вместо них инициалы. Контакты не заполнены: после внесения реальных адресов в `data/store.json` появится ссылка для письма. Внутренний чат и самостоятельное редактирование профилей пока не реализованы.


### Обновление раздела экспертов
- Сохранены поиск по имени, категории и возврат к списку.
- В карточках кнопка «Задать вопрос»; стрелка открывает профиль. Вопросы сохраняются в JSON (без отправки в Битрикс24).
- Профиль: «Спроси меня про…», основание экспертности, компетенции, тематические ачивки (если они указаны в общей записи эксперта).
- Эксперт, привязанный к аккаунту, может редактировать свое описание и компетенции. Администратор назначает, редактирует и отключает экспертов.
- Верхнее меню убрано; остается боковое меню на десктопе.
- Отложено: поиск по компетенциям, интеграция Битрикс24, кнопка сообщения в Битрикс24, доработка мобильной версии.


## Анкета перед стартом

После входа участник без анкеты автоматически видит форму; прямая ссылка: `/anketa`. В анкете есть три сезона, выбор 1–3 целей на сезон, достижения и готовность быть экспертом. Ответы сохраняются в `data/store.json` по ID пользователя. После первого сохранения редактирование доступно 72 часа, если администратор не закрыл анкету раньше. В админке есть статус заполнения, общая дата закрытия и распределение по общим целям с утверждением. Старые данные, разделы и учетные записи сохранены.

Важно: список офисов сейчас демонстрационный, замените его на действующий список офисов BGP. Дата закрытия интерпретируется в часовом поясе сервера. Распределение работает только для заполнивших анкету, а существующие назначения пользователей без анкеты не изменяются. Для реального размещения используйте HTTPS, ограничьте доступ к файлу базы и замените демонстрационные пароли.

## Распределение по командам

В админке откройте «Анкетирование» → «Распределение по командам». После заполнения анкет минимум 10 участниками нажмите «Распределить участников». Появится черновик 10 команд с численностью, сходством целей и участниками. Можно перемещать участников между командами; при утверждении система проверит равную численность и актуальность анкет. Нажмите «Утвердить команды», чтобы открыть результаты участникам. До утверждения составы скрыты. Анкеты доступны администратору по кнопке «Посмотреть ответы», экспорт в Excel-совместимый CSV.

Алгоритм: коэффициент Жаккара по каждой из трех категорий целей, среднее с равными весами, детерминированные обмены между командами с ограничением численности. Если анкеты изменились, черновик отмечается устаревшим. В тестовой базе только один участник и нет заполненных анкет, поэтому для проверки распределения нужно создать минимум 10 пользователей и заполнить их анкеты.

Сохранены существующие разделы и данные. Перед обновлением работающей версии сделайте резервную копию `data/store.json`.

## Чат привычек (обновление)

Раздел «Чат» показывает цели текущего сезона из регистрационной анкеты (или исходную цель профиля, если анкеты нет). Для каждой цели доступны кнопки «Выполнено» и «Не получилось». Ответ сохраняется через `POST /api/bot_check` в том же массиве `checks`, что и прежние отметки. Ключ записи: участник + дата + сезон + привычка. Повторное нажатие заменяет ответ. `GET /api/state` возвращает актуальные показатели, привычки и признак напоминания.

Прогресс рассчитывается как число выполненных привычек / (21 × число привычек сезона). Успешным считается день с хотя бы одной выполненной привычкой; достижения начисляются по числу таких дней. Командный рейтинг использует прежнее правило нулевого вклада при личном прогрессе ниже 50%. На главной странице отображаются статусы привычек, успешные дни, прогресс, ачивки и командный результат.

Напоминание реализовано внутри приложения: при открытии «Чата» в день с отсутствующими отметками отображается приглашение заполнить ответы. Автоматическая отправка push-уведомлений в закрытое приложение не реализована: для нее необходимы серверный планировщик, подписки Web Push и разрешения пользователей.


## Тестовое распределение
В админке выберите 2 команды (тест) или 10 команд (марафон), затем нажмите «Распределить участников». При 10 участниках и 2 командах формируются две группы по 5 человек. Алгоритм максимизирует сходство выбранных целей при равной численности. Сначала создается черновик; для сохранения состава нажмите «Утвердить команды». Если распределение уже утверждено, повторный запуск через интерфейс заблокирован. Данные пользователей и анкет сохранены из исходного архива.
